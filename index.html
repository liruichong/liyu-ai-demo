礼遇 LiYu · 产品方案

送礼 AI 助手 —— 认识你想送的人，记得你送过的心意，在对的日子把礼物送到心坎里。

00 · 项目背景

  • 缘起：送礼是高频刚需，但「选什么、送给谁、怎么写话」长期靠临时搜、靠人肉记，没人帮用户把「那个人」记牢、把话说到位。
  • 机会：内容电商（小红书）已把「种草 → 下单」跑通，但前面的「决策」环节——懂人、选对、说好——仍是空白，礼遇正是来补这一段。
  • 定位：纯推荐型送礼 AI 助手，帮用户「认识想送的人、选对礼物、说好心意、记住日子」，成交交给成熟电商，不碰供应链。

01 · 痛点与问题

不知道送什么

对着搜索框不知道搜啥，刷 3 个 App、来回切 2 小时，还是拿不定主意。

怕送错踩雷

不记得对方的禁忌、过敏、雷区，花了钱反而不讨好、还尴尬。

容易忘日子

生日、纪念日、节日一忙就忘，只能临时抱佛脚、买贵的糊弄。

不会说走心话

礼物送出去了，却不知道写什么，心意打了折。

本质：送礼难在「懂人」，不在「找货」—— 商品随处可买，难的是把「这个人」看明白、把话说到位。

02 · 目标用户与用户洞察

市场

中国礼赠市场是「万亿元级」生意，亲密 / 人情关系的礼赠高频、高复购，是最大基础盘。（精确值以艾媒咨询等最新报告为准）

人群

20~35 岁是礼赠主力，决策特征是「怕错」大于「怕贵」，更愿为情绪价值付费。（待引 QuestMobile / 艾瑞数据）

决策

记错日子、买错雷区、说不出走心话，是高频踩坑点，不是低频刚需。

转化

小红书已成年轻人「被种草 → 下单」的主要路径，礼赠天然契合内容种草。

核心洞察

送礼是「关系维护」行为，决策成本在「懂人」不在「找货」。商品处处可买，难的是把这个人看明白、把话说到位。

核心用户 A —— 亲密 / 人情送礼者（20~35 岁），向下细分 4 类人群（性别 / 年龄为公开趋势归纳，精确占比待引权威报告）：

🩷 A1 · 热恋 / 新婚情侣

  • 性别构成：男女均衡，女性略高（更愿张罗仪式感礼物）
  • 年龄：23~32 岁
  • 人生阶段：恋爱稳定期 / 新婚 0~5 年，一二线为主
  • 人群属性：重仪式感、情绪价值敏感、社交分享欲强
  • 驱动：证明爱与重视，建立仪式感
  • 动机：不想踩雷拉低关系，要「惊喜感 + 被懂」
  • 时机/预算：纪念日·生日·520·七夕；200~1000+ 弹性大

🌷 A2 · 孝心儿女

  • 性别构成：女性为主（女儿更愿为父母花心思）
  • 年龄：25~35 岁
  • 人生阶段：职场成长期，父母渐入退休 / 银发期，跨线级、异地打拼多
  • 人群属性：愧疚感驱动的「情绪型尽孝」，注重实用健康
  • 驱动：亏欠感与感恩，想让爸妈「享点好的」
  • 动机：长辈难选（不在意物质·忌口·健康），怕买错闲置
  • 时机/预算：生日·春节·中秋·父母节；200~1500 实用健康类

🎀 A3 · 闺蜜挚友

  • 性别构成：女性为主（闺蜜经济核心）
  • 年龄：20~30 岁
  • 人生阶段：求学 / 初入职场 / 异地发展，同学、同事、发小
  • 人群属性：圈层审美、颜控、「站队式」友谊认同、分享型消费
  • 驱动：友谊认同与「站队」，圈层审美
  • 动机：要「懂我」的颜控好物，拒绝「敷衍」
  • 时机/预算：生日·搬家·毕业·结婚；100~500 颜值情绪类

💘 A4 · 暧昧 / 追求期

  • 性别构成：男性居多（追求方多为男性）
  • 年龄：20~28 岁
  • 人生阶段：单身，暗恋 / 追求 / 表白前
  • 人群属性：分寸敏感、怕越界、需要「助攻话术」、低预算试探
  • 驱动：推进关系的冲动与分寸拿捏
  • 动机：既想表达又怕越界，需要分寸 + 表白话术
  • 时机/预算：心动瞬间·表白；100~300 分寸型小物

次级用户 B · 轻量人情往来

  • 性别构成：男女均衡
  • 年龄：25~40 岁
  • 人生阶段：职场中坚，有稳定社交圈，同事 / 客户 / 普通亲戚
  • 人群属性：处事得体、「不出错 > 出彩」、时间敏感
  • 驱动：人情世故的得体与省心
  • 动机：不出错、拿得出手、别花太多时间
  • 时机/预算：节日·答谢；100~500 标准礼盒 / 通用款

商务 / 企业团购暂不覆盖，作为二期独立规划。

首次进入分三步引导：添加收礼人 → 体验送礼推荐 → 标记重要日子，可跳过、可重复查看。

逐字生成走心话术，可一键复制。

5

跳小红书商城成交（主），淘宝 / 京东为辅，回来后记录「送了什么、对方反应」。

05 · 竞品分析

小红书（内容种草电商）

  • 擅长：内容种草、场景化激发购买欲、年轻心智强
  • 缺失：「逛着逛着想买」，不解决「送谁、送什么、怎么写话」
  • 礼遇差异：从「人」出发给决策；小红书是礼遇的成交主路径（竞合）

淘宝 / 京东（货架电商）

  • 擅长：商品全、履约快、比价透明
  • 缺失：「搜什么」是最大门槛，礼赠场景颗粒度粗
  • 礼遇差异：作为辅助成交渠道，礼遇承担「前置决策」

礼物说 / 生日管家

  • 擅长：节日提醒、愿望清单、日历
  • 缺失：推荐偏「礼物目录」，缺「懂这个人」的记忆与理由
  • 礼遇差异：把「关系档案」做成可复用资产，越用越准

通用 AI（豆包 / ChatGPT）

  • 擅长：出主意、写文案能力强
  • 缺失：不记人（每次重新交代）、不落地成交、缺领域约束
  • 礼遇差异：领域化 AI + 关系记忆 + 成交闭环
定位结论

礼遇的机会空位 = 把「关系记忆」做成资产，串起「懂人 → 选对 → 说好 → 记住 → 买对」的垂直闭环。以上四类竞品都不是这块的完整方案。

06 · 产品方案

一句话：让送礼从「搜商品」变成「懂一个人」。

产品形态

  • 形态：移动端 H5 优先、单列滚动，首页即「送礼助手」，主路径 = 首页 → 选礼流 → 礼物详情 → 跳转成交。
  • 一级结构：底部「首页 / 发现 / [AI 助手·中凸] / 心愿 / 我的」；首页放大「为 TA 送礼」入口 + 功能宫格，发现合并「搜索 + 分类 + 活动 + 攻略 + 商城」。
  • 纯推荐闭环：只做「选对 + 说好 + 记住」，成交跳小红书商城（主）/ 淘宝京东（辅），不碰库存、履约、支付。

核心价值

  • 把「人」变成可复用档案（关系 / 兴趣 / 禁忌 / 预算 / 送过什么），入口是「人」不是「货」
  • 把「选礼」从目录筛选变成「由人出发的决策」：候选 + 理由 + 雷区
  • 把「表达」做成产品能力：有分寸、不踩雷的寄语一键生成
  • 把「记忆」做成复利资产：越用越懂、越用越省心

核心功能模块（按承载用户价值，非按 Tab）

认识 TA · 关系档案

对话式录入关系、兴趣、禁忌、预算、重要日期；一人一档，成为后续一切推荐的「上下文」。

选对 · 智能选礼

输入「给谁 + 场景 + 预算 + 风格」，输出 N 个候选 + 推荐理由 + 雷区提示。

说好 · 走心寄语

按关系、场景生成话术，自动规避雷区，可一键复制。

记住 · 日历记录

日子提醒 + 送过的礼 + 对方反馈，形成记忆闭环，反哺下次推荐。

礼尚往来 · 双向台账

送出 / 收到双向快记，自动算「该回一份心意」的时机与分寸，耦合日历、为 TA 选礼、关系档案与心意贺卡。

买对 · 跳转成交

主路径跳小红书商城（种草心智契合），淘宝 / 京东为辅。

随时问 · AI 参谋

底部中凸 AI 入口，随时进入对话问「该送什么」，AI 结合关系档案给建议。

信息架构

  • 一级导航（底部）：首页 ｜ 发现 ｜ [AI 助手·中凸] ｜ 心愿 ｜ 我的
  • 首页：为 TA 送礼 Hero（礼物 emoji 占位，放大）+ 四个功能入口（人物关系 / 送礼日历 / 礼尚往来 / 心意贺卡）+ 惊喜盲盒入口 + 日期日历（内嵌「送礼日倒计时」整行卡片，左右自动滑动）
  • 发现：顶部搜索栏 → 分类导航（为谁挑 / 为何送左右切，分类可点进二级页）→ 活动 banner（自动轮播）→ 送礼攻略卡片（横滑）→ 礼物商城（双栏瀑布流）；分类二级页仅保留「搜索 / 攻略 / 商城」三模块
  • 心愿：心愿池（收藏礼物）+ 历史送过记录
  • 我的：关系与档案 / 提示与设置 / 帮助（含再次查看新手引导）
  • AI 助手：底部中凸入口，进入即对话
  • 选礼流：选人 → 选场景 / 预算 / 风格 → 出方案 → 看礼物 → 生成寄语 → 跳转成交
  • 礼物详情：礼物信息 + 推荐理由 + 雷区 + 寄语 + 跳转按钮
  • 新手引导：首次进入分步教「添加人物 → 送礼推荐 → 节点提醒」，可跳过

视觉策略

设计原则（大策略）

  • 年轻化：贴近 20~35 岁审美，轻快不油腻、不「爸妈风」，一眼有代际认同
  • 艺术感：有审美辨识度与记忆点，拒绝冷白货架感，让人一进就觉得「有品味」
  • 温暖感：送礼的情绪底色，暖而不腻、有拥抱感，而不是促销的躁
  • 人情味：有人味、有温度，是「用心准备」的气场，不是冷冰冰的机器推荐

落地抓手（具体策略）

  • 颜色：白底为主 + 正红品牌强调 + 浅黄/天蓝双辅助色，清爽中带热烈与信任
    白底 #FFFFFF（主背景） 正红 #ee3c38（品牌强调） 浅黄 #F7F5CD（辅助·暖） 天蓝 #50acff（辅助·信任）
  • 视觉风格：柔和渐变 + 大圆角 + 留白呼吸，情绪化 emoji / 插画做情感占位
  • Icon 设计：线条 + 面性结合、统一圆角与栅格，情感化微动效（节日彩蛋、礼物点亮）
  • 卡片设计：统一卡片规范——16px 圆角、1px 浅描边、统一留白；一张卡片只讲一件事，文字版式分三级（标题 15px / 正文 13px / 辅助 11px），层级清晰、点面可点
  • 文案规范：去掉口号与装饰性文字，卡片与文字只保留功能信息，简洁、可扫读
  • 跳转方式：卡片即入口，一键跳小红书商城（主）/ 淘宝京东（辅），不打断送礼情绪
  • 内容结构：移动端优先、单列滚动 + 宫格 + 横滑 + 瀑布流混排，契合单手使用

07 · AI 价值与在产品中的作用

AI 不是「搜索引擎」，是「懂关系的参谋」——四项能力分别落在四个功能模块上，是产品「懂人 → 选对 → 说好 → 记住」这条主线的发动机。

理解人

落在「认识 TA · 关系档案」——解析收礼人画像（关系 / 兴趣 / 禁忌 / 预算），把零散信息结构化入档。

推荐精准

落在「选对 · 智能选礼」——由人出发给候选 + 理由 + 雷区；AI 管理解与解释，排序走规则引擎保证稳定不幻觉。

表达情

落在「说好 · 走心寄语」——按关系、场景生成有分寸的寄语与送礼理由，一键复制。

记得住

落在「记住 · 日历记录」——记忆日期、送过什么、对方反馈，主动提醒、反哺下次推荐。

随时答

落在底部「AI 参谋」对话——不打断主流程的轻量入口，结合关系档案即时回应「该送什么」。

AI 的边界：AI 管「理解 + 表达 + 解释」，不独占「排序」——推荐排序走规则引擎（可解释、不幻觉）；「买对 · 跳转成交」由电商承接，AI 不碰供应链与交易；不编造画像、不越关系分寸、合规硬截断。

08 · 关键取舍

纯推荐 · 不碰供应链

成交跳转小红书商城（主）+ 淘宝 / 京东（辅），聚焦「选对」而非「卖货」。

以人为中心

核心路径 = 人 → 选礼，而非礼物 → 搜商品。

规则引擎先行

先可解释的规则推荐，跑顺了再上大模型。

亲密 / 人情优先

先服务亲密 / 人情关系，商务分群二期独立。

数据先轻后重

先用 mock / 黄页跑通体验，再逐步接真实商品与画像数据。
